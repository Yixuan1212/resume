## 🚀 如何更新至 GitHub Pages？

### 方式一：直接在 GitHub 網頁上傳更新（最推薦）
1. 開啟您的 GitHub 倉庫：[https://github.com/Yixuan1212/resume](https://github.com/Yixuan1212/resume)
2. 點擊右上方的 **「Add file」** ➜ **「Upload files」**。
3. 將本目錄中的 `index.html` 與 `README.md` 拖曳到上傳區域中。
4. 於下方 Commit 訊息輸入（例如：`Add medical aesthetics industry analysis portfolio with interactive charts`），點擊 **「Commit changes」**。
5. GitHub Pages 將在 1~2 分鐘內自動重新建置並發布最新版網站！
