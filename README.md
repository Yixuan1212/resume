# 許益瑄 - 個人履歷網站 (Resume Website)

這是一份專為 **許益瑄** 設計的個人履歷響應式網站，資料完全嚴格依據個人真實資料製作，無任何虛構內容。

---

## 🌟 網站特色
- **完全真實資料**：包含醫美診所助理實務經驗、萬能科大企管系學歷、四大核心技能與自傳優勢。
- **響應式設計**：支援手機、平板、電腦螢幕最佳化瀏覽體驗。
- **一鍵列印/轉 PDF**：提供專屬列印樣式，可一鍵轉存為高畫質 PDF 履歷。
- **支援 GitHub Pages 免費部署**：單一靜態網頁架構，零依賴、秒載入。

---

## 🚀 如何部署至 GitHub Pages？

### 方式一：透過 GitHub 網頁上傳（最簡單，免安裝任何軟體）
1. 登入您的 [GitHub](https://github.com/) 帳號。
2. 點擊右上角的 **「+」** ➜ 選擇 **「New repository」**。
3. 設定 Repository name（例如：`resume`），選擇 **Public**（公開），並點擊 **Create repository**。
4. 在建立好的專案頁面中，點擊 **「uploading an existing file」**。
5. 將本資料夾內的 `index.html` 與 `README.md` 直接拖曳上傳，並點擊 **Commit changes**。
6. 進入專案的 **Settings**（設定） ➜ 點選左側 **Pages**。
7. 在 **Branch** 下拉選單選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
8. 等待 1~2 分鐘，上方就會顯示您的專屬免費履歷網址（例如：`https://<您的帳號>.github.io/resume/`）！
